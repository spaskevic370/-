# Простой интерпретатор арифметических выражений

Вариант 46: функция `abs()` и побитовое И (`&`).

## Что умеет

- Целые и дробные числа: `42`, `3.14`, `.5`, `1.`
- Операторы: `+`, `-`, `*`, `/`
- Унарные `+` и `-`: `-5`, `--3`
- Скобки: `(2 + 3) * 4`
- Функция `abs(...)` — модуль числа
- Побитовое И `&` — только для целых
- Проверка деления на ноль
- Сообщения об ошибках

## Приоритет операций (высший → низший)

1. `abs(...)`, `(...)`, числа
2. Унарные `+`, `-`
3. `*`, `/`
4. `+`, `-`
5. `&`

## Примеры

| Выражение | Результат |
|-----------|-----------|
| `2 + 3 * 4` | `14` |
| `(2 + 3) * 4` | `20` |
| `abs(-5)` | `5` |
| `abs(2 + 3) & 7` | `5` |
| `10 - 3 - 2` | `5` |
| `--5` | `5` |
| `5 & 3` | `1` |
| `2 & 3.0` | ошибка: нужны целые числа |
| `1 / 0` | ошибка: на ноль делить нельзя |
| `1.2.3` | ошибка: неправильно записано число |
